## ADDED Requirements

### Requirement: Full-width desktop article column
Documentation pages SHALL omit the right page outline and use its space for text and code up to the right edge of the content grid.

#### Scenario: Read on desktop
- **WHEN** a documentation page is opened on a wide screen
- **THEN** the article occupies all grid columns to the right of the section navigation
- **AND** there is no separate page-outline column
