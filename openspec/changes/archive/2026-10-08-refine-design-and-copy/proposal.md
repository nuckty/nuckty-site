# Refine website design and copy

## Why
The first viewport is dominated by whitespace and a large code sample. Generic headlines conceal what nuckty does, and alphabetical documentation navigation does not support learning.

## What Changes
Use a compact product entry, exact source/template/output panels, factual bilingual copy, ordered documentation and mobile navigation controls.

## Impact
Changes consumer blocks, preparation and product copy; preserves canonical docs, routes and logo.
